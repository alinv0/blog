# alinvoinea.eu — Blog

Articles and discussions for [alinvoinea.eu](https://www.alinvoinea.eu).

Each article is a directory with a `content.md` file (markdown with YAML frontmatter) and optional images. The `inventory.json` file is the master index, auto-generated by the publish script.

## Structure

```
articles/
  my-article/
    content.md      # Article content (markdown + frontmatter)
    image.png       # Optional images
  inventory.json    # Master index (auto-generated)
```
